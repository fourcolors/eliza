# Step 2: Action Implementation
-------------------------
Purpose: Implement pure action functions for Hyperlane message dispatch and token transfers

Design Decisions:
1. Action Purity:
   - All actions are pure functions
   - Actions receive dependencies via parameters
   - No internal state management
   Justification: Pure functions enable better testing and composition

2. Token Standards:
   - Support for ERC20, ERC721, and ERC4626
   - Type-safe token interfaces
   - Pure token operations
   Justification: Following Hyperlane's supported token standards

3. Error Handling:
   - Pure error types
   - Functional error handling with Either type
   - No exceptions for control flow
   Justification: Predictable error handling and composition

Actions:
1. Pure Action Types
   ```typescript
   export type ActionResult<T> = Readonly<{
     success: boolean;
     data?: T;
     error?: string;
     metadata: ReadonlyMap<string, unknown>;
   }>;

   export type TokenType = 'erc20' | 'erc721' | 'erc4626' | 'native';

   export type TransferParams = Readonly<{
     tokenType: TokenType;
     token: string;
     amount: string;
     recipient: string;
     destinationDomain: number;
     metadata?: ReadonlyMap<string, unknown>;
   }>;
   ```

2. Pure Action Functions
   ```typescript
   export const createTransferAction = (
     hyperlane: Readonly<HyperlaneService>,
     storage: Readonly<StorageService>
   ) =>
     async (
       params: Readonly<TransferParams>
     ): Promise<Readonly<ActionResult<string>>> => {
       const validateParams = createParamsValidator();
       const validationResult = await validateParams(params);
       
       if (!validationResult.success) {
         return validationResult;
       }

       const executeTransfer = createTransferExecutor(hyperlane);
       const transferResult = await executeTransfer(params);
       
       if (!transferResult.success) {
         return transferResult;
       }

       const saveTransfer = createTransferSaver(storage);
       await saveTransfer({
         ...params,
         messageId: transferResult.data,
         timestamp: Date.now()
       });

       return transferResult;
     };

   export const createMessageAction = (
     hyperlane: Readonly<HyperlaneService>
   ) =>
     async (
       params: Readonly<MessageParams>
     ): Promise<Readonly<ActionResult<string>>> => {
       const mailbox = await hyperlane.getMailbox(params.destinationDomain);
       
       try {
         const messageId = await mailbox.dispatch(
           params.destinationDomain,
           params.recipient,
           params.body
         );

         return {
           success: true,
           data: messageId,
           metadata: new Map([
             ['timestamp', Date.now()],
             ['domain', params.destinationDomain]
           ])
         } as const;
       } catch (error) {
         return {
           success: false,
           error: error.message,
           metadata: new Map([
             ['timestamp', Date.now()],
             ['error', error]
           ])
         } as const;
       }
     };
   ```

3. Pure Validation Functions
   ```typescript
   export const createParamsValidator = () =>
     async (
       params: Readonly<TransferParams>
     ): Promise<Readonly<ActionResult<void>>> => {
       const validations = [
         validateTokenType,
         validateAmount,
         validateRecipient,
         validateDomain
       ].map(v => v(params));

       const errors = (await Promise.all(validations))
         .filter(result => !result.success)
         .map(result => result.error);

       if (errors.length > 0) {
         return {
           success: false,
           error: errors.join(', '),
           metadata: new Map([['validationErrors', errors]])
         } as const;
       }

       return { success: true } as const;
     };
   ```
