6. Example Documentation
   ```markdown
   # Message Processing Guide

   ## Pure Message Handler

   Create a message handler using pure functions:

   ```typescript
   const handler = createMessageHandler({
     validators: ['origin', 'security'],
     processors: ['decode', 'verify']
   });

   const result = await handler.process({
     id: '0x123',
     origin: 'ethereum',
     data: '0x456'
   });
   ```

   ## Chain Integration

   Configure chains using pure functions:

   ```typescript
   const chain = await configureChain({
     name: 'optimism',
     rpc: 'https://rpc1.example.com'
   });

   const connection = await chain.connect();
   ```

   ## Testing

   Create and run tests using pure functions:

   ```typescript
   const suite = createTestSuite('Message Tests', [
     {
       name: 'processes valid message',
       input: createMessage({
         id: '0x123',
         origin: 'ethereum'
       }),
       expected: { success: true }
     }
   ]);

   const results = await runTestSuite(suite);
   ```
