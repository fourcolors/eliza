# Hyperlane Integration Coordinator

This document coordinates the implementation of the Hyperlane plugin for ElizaOS.
Follow these guidelines for all development work.

## Required Documentation
- [ElizaOS Core Docs](https://elizaos.github.io/eliza/docs/core)
- [Hyperlane Protocol Docs](https://docs.hyperlane.xyz)
- [Plugin Architecture](https://elizaos.github.io/eliza/docs/plugins)

## Implementation Process

1. Always start by checking the implementation checklist in `implementation-checklist.md`
2. For each task:
   a. Verify requirements in the documentation
   b. Implement the feature
   c. Add tests
   d. Update documentation if needed
   e. Run `git-commit.txt` to commit changes
   f. Have changes reviewed via `commit-reviewer.txt`
   g. Update implementation checklist
   h. Double check docs before moving to the next task

## Development Guidelines

### Code Quality Requirements
1. Functional Programming
   - Use immutable data structures
   - Write pure functions
   - Isolate side effects
   - Apply design patterns

2. Testing Protocol
   - Write tests before implementation
   - Use vitest
   - Cover edge cases
   - Achieve ≥85% coverage
   - Run test that run automatically (no watching)

3. Documentation
   - Keep docs updated
   - Document design decisions
   - Use block comments only for non-obvious code

4. Security & Performance
   - Validate all inputs
   - Implement retry mechanisms
   - Optimize gas usage
   - Follow security best practices

## Implementation Status
See `implementation-checklist.md` for detailed progress tracking.

## Git Workflow
1. Before starting work:
   - Check implementation-checklist.md for next task

2. During development:
   - Make atomic commits
   - Follow commit message guidelines
   - Update implementation checklist

3. Before committing:
   - Run all tests without without "watch mode"
   - Update documentation
   - Follow git-commit.txt instructions
   - Get review via commit-reviewer.txt

4. After completing a task:
   - Update implementation-checklist.md
   - Get final review

## Important Files
- implementation-checklist.md: Source of truth for implementation progress
- git-commit.txt: Instructions for making commits
- commit-reviewer.txt: Guidelines for code review
