# Step 5: Cross-Chain Messaging Setup
-------------------------
Documentation References:
- ElizaOS Messaging: https://elizaos.github.io/eliza/docs/messaging/
- Hyperlane Send Message: https://docs.hyperlane.xyz/docs/reference/messaging/send
- Hyperlane Post-Dispatch Hooks: https://docs.hyperlane.xyz/docs/reference/hooks/overview

Purpose: Implement pure functions for cross-chain message dispatch and handling

Design Decisions:
1. Message Handling:
   - Pure message creation functions
   - Immutable message types
   - Composable message handlers
   Justification: Maintain functional purity in messaging

2. Fee Management:
   - Pure fee calculation functions
   - Immutable fee quotes
   - Composable fee handlers
   Justification: Predictable and pure fee handling

3. Hook Configuration:
   - Pure hook setup functions
   - Immutable hook configs
   - Composable hook chains
   Justification: Flexible and pure hook management

Actions:
1. Pure Message Types

   export type MessageConfig = Readonly<{
     destinationDomain: number;
     recipientAddress: string;
     messageBody: string;
     metadata?: ReadonlyMap<string, unknown>;
   }>;

   export type FeeQuote = Readonly<{

   export type HookConfig = Readonly<{

2. Pure Message Functions
   ```typescript
   export const createMessageDispatcher = (
     hyperlane: Readonly<HyperlaneService>
   ) =>
     async (
       config: Readonly<MessageConfig>
     ): Promise<Readonly<Result<string>>> => {
       // Get mailbox for destination
       const mailbox = await hyperlane.getMailbox(config.destinationDomain);
       
       // Quote dispatch fee
       const quote = await mailbox.quoteDispatch(
         config.destinationDomain,
         addressToBytes32(config.recipientAddress),
         config.messageBody
       );

       try {
         const messageId = await mailbox.dispatch(
           config.destinationDomain,
           addressToBytes32(config.recipientAddress),
           config.messageBody,
           { value: quote }
         );

         return {
           success: true,
           data: messageId,
           metadata: new Map([
             ['fee', quote.toString()],
             ['timestamp', Date.now()]
           ])
         } as const;
       } catch (error) {
         return {
           success: false,
           error: {
             code: 'DISPATCH_FAILED',
             message: error.message,
             context: new Map([
               ['config', config],
               ['quote', quote]
             ]),
             timestamp: Date.now(),
             recoverable: true
           },
           metadata: new Map()
         } as const;
       }
     };

   export const createFeeQuoter = (
     hyperlane: Readonly<HyperlaneService>
   ) =>
     async (
       config: Readonly<MessageConfig>
     ): Promise<Readonly<FeeQuote>> => {
       const mailbox = await hyperlane.getMailbox(config.destinationDomain);
       const fee = await mailbox.quoteDispatch(
         config.destinationDomain,
         addressToBytes32(config.recipientAddress),
         config.messageBody
       );

       return {
         fee: fee.toString(),
         gasLimit: calculateGasLimit(config),
         timestamp: Date.now(),
         metadata: new Map([
           ['domain', config.destinationDomain],
           ['recipient', config.recipientAddress]
         ])
       } as const;
     };
   ```

3. Pure Hook Functions
   ```typescript
   export const createHookConfigurator = (
     config: Readonly<HookConfig>
   ) =>
     async (
       mailbox: Readonly<IMailbox>
     ): Promise<Readonly<Result<void>>> => {
       try {
         // Configure required hooks
         for (const hook of config.required) {
           await mailbox.setRequiredHook(hook);
         }

         // Configure default hooks
         for (const hook of config.default) {
           await mailbox.setDefaultHook(hook);
         }

         return {
           success: true,
           metadata: new Map([
             ['requiredHooks', config.required],
             ['defaultHooks', config.default]
           ])
         } as const;
       } catch (error) {
         return {
           success: false,
           error: {
             code: 'HOOK_CONFIG_FAILED',
             message: error.message,
             context: new Map([['config', config]]),
             timestamp: Date.now(),
             recoverable: true
           },
           metadata: new Map()
         } as const;
       }
     };
   ```
